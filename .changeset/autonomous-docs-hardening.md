Docs system hardening (chore/docs): enforce the documentation gates that were
previously only advisory, and add a file-level doc-classification gate.

- `docs:asvs` (ASVS coverage `--check`) now runs in CI `hygiene` and is
  regenerated by the `resync` bot (docs/reference/asvs-coverage.md + its
  snapshot) — previously this generated-doc gate was not enforced in CI.
- New `docs:manifest` gate (`scripts/check-manifest.mjs` +
  `docs/manifest.yaml`) forces every tracked markdown doc to be classified —
  generated / fact-markered / ADR / standalone-review-dated — and fails the
  build on unclassified docs or 180-day-expired prose reviews. Wired into
  `docs:all` and CI `hygiene`.
- New `.husky/pre-push` hook runs `build && docs:all` before a push leaves
  the machine.
- `/DOC-AUDIT.md` (default output of `usa docs audit`) is now gitignored.
- Adds DOCS_AUDIT_REPORT.md, DOCS_SYSTEM_DESIGN.md, DOCS_VERIFICATION_LOG.md.

No shipped runtime API changes; dev/doc-experience only (patch).
